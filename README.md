- ตัวโปรแกรมทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว (HTML/CSS/JS) ไม่ต้องมีเซิร์ฟเวอร์แยก
  ใช้ Supabase เป็นฐานข้อมูล + ระบบล็อกอิน และ GitHub Pages เป็นตัวเปิดหน้าเว็บ

## เวรและกฎการจัดเวร (สรุป)

**รหัสเวร:** ช เช้า 08:00–16:00 · บ บ่าย 16:00–24:00 · ด ดึก 00:00–08:00 (เวรละ 8 ชม.) ·
ชบ ควบเช้า+บ่าย (นับ 2) · VA ลาพักผ่อน · X ขอหยุด/Off · T ประชุม/อบรม · ML ลาคลอด
ตัวดำ = เวรปกติ · ตัวแดง = เวร OT

**กฎหลัก** (⚡ จัดเวรอัตโนมัติทำตาม และ ✅ ตรวจกฎจะแจ้งเมื่อผิด):

- ห้าม บ แล้ววันรุ่งขึ้น ด (บ เลิก 00:00 = ด เริ่ม 00:00 ไม่ได้พัก) · ช → ด วันรุ่งขึ้นได้ · ด → ช วันรุ่งขึ้นได้
- เวรดึกติดกันไม่เกิน 2 วัน แล้ววันถัดไปลงได้แค่ **บ่าย หรือ หยุด** (นับรวม OT, ไม่ผูกกับชื่อวัน)
- หลังวัน X ไม่จัดเวรดึก
- ขึ้นเวรติดกันไม่เกิน 6 วัน และหยุดอย่างน้อย 1 วัน/สัปดาห์ (นับเฉพาะตารางเวรหลัก) · ไม่เกิน 12 เวร/สัปดาห์ (รวม OT)
- ขอหยุด/ลา (X + VA) ไม่เกิน 7 วัน/เดือน
- ทุกเวรต้องมีพยาบาลวิชาชีพชำนาญการ (รวมหัวหน้าหอ) อย่างน้อย 1 คน
- หัวหน้าหอ/รองหัวหน้า: เช้าทุกวันทำการ · ไม่มีเวรดึก · บ่ายลงได้เฉพาะตารางโอที · วันอาทิตย์หยุด

**อัตรากำลัง (👥):** ตั้งจำนวนคนต่อเวร ช/บ/ด แยก วันธรรมดา / เสาร์ / อาทิตย์ / วันหยุดราชการ
และแยก พยาบาล กับ ผู้ช่วยฯ/พนักงาน · **ตั้งแยกได้รายเดือน** (เดือนที่ไม่ได้ตั้ง = ค่าเริ่มต้น) ·
ปุ่ม ⚖️ ปรับอัตรากำลังตามวันทำการ ให้ระบบเสนอจำนวนคนตาม OT เป้าหมายเฉลี่ยต่อคน

## สูตรคิด OT

**OT (เวร) = เวรที่ขึ้นทั้งเดือน (ตารางหลัก + ตารางโอที, เวรควบนับ 2) + VA + T − วันทำการ**
(วันทำการ = จันทร์–ศุกร์ ไม่รวมวันหยุดราชการ · หักวันลาคลอดที่ตรงวันทำการ)

เวรปกติ (ตัวดำ) ต่อคน ตามจำนวนวันทำการของเดือน — ส่วนที่เกินในแต่ละประเภท = OT (ตัวแดง)

| วันทำการ | เช้า | บ่าย | ดึก |
|---|---|---|---|
| 18 | 6 | 6 | 6 |
| 19 | 6 | 6 | 7 |
| 20 | 6 | 7 | 7 |
| 21 | 7 | 7 | 7 |
| 22 | 8 | 7 | 7 |
| 23 | 8 | 8 | 7 |

ตัวอย่าง: ก.ย. 69 มี 22 วันทำการ ขึ้น ช16 บ10 ด9 → OT = (16−8) + (10−7) + (9−7) = **13 เวร**
แก้ตารางนี้ได้ที่ 👥 อัตรากำลัง หรือ 💰 ตั้งค่า OT ③ · ⚡ จัดเวรอัตโนมัติใช้สูตรนี้และเกลี่ย OT ให้แต่ละคนใกล้เคียงกัน

อัตรา (ค่าเริ่มต้น แก้ได้ที่ 💰 ตั้งค่า OT): พยาบาลอายุงาน 5 ปีขึ้นไป 850 บาท · ต่ำกว่า 5 ปี 800 บาท ·
ผู้ช่วยพยาบาล 475 บาท · พนักงานช่วยเหลือคนไข้/อื่น ๆ 450 บาท ·
ค่าเวรบ่าย-ดึก ทุกเวร บ/ด ที่ขึ้นจริง 360 บาท (พยาบาล) / 120 บาท (ผู้ช่วยฯ/อื่น ๆ) — หัวหน้าหอไม่ได้

## ฐานข้อมูล Supabase

โปรเจกต์: `mpuvzknihminrxoxkeas` (URL และ publishable key ใส่ไว้ใน `index.html` แล้ว — key นี้เป็นค่าสาธารณะ ใส่ในหน้าเว็บได้)

| ส่วน | ใช้ทำอะไร |
|---|---|
| ตาราง `nurse_schedule_data` | ข้อมูลตารางเวรทั้งหน่วยงาน (1 แถว/หน่วยงาน, JSON) |
| ตาราง `app_users` | บัญชีผู้ใช้ + บทบาท (admin / head / deputy / nurse) + ผูกกับรายชื่อพยาบาล |
| ตาราง `username_directory` | จับคู่ชื่อผู้ใช้ → บัญชีล็อกอิน (ล็อกอินด้วยชื่อผู้ใช้ ไม่ต้องใช้อีเมลจริง) |
| ตาราง `day_requests` + ฟังก์ชัน `submit_day_request` | คำร้อง Request Day (สร้างจาก `supabase_day_requests.sql`) |
| Edge Function `admin-reset-password` | ให้แอดมินรีเซ็ตรหัสผ่าน / เปิดบัญชีเดิมกลับมา |

ทุกตารางเปิด Row Level Security (RLS) — แต่ละหน่วยงานเห็นเฉพาะข้อมูลของตัวเอง

### ตั้งค่าที่ต้องทำใน Supabase (ครั้งเดียว)

1. **Authentication → Providers → Email:** ปิด "Confirm email"
2. **SQL Editor → New query:** วางเนื้อหา `supabase_day_requests.sql` → **Run**
   (ต้องรันใหม่ทุกครั้งที่ได้ไฟล์นี้เวอร์ชันใหม่)
3. **Edge Functions:** ต้องมี `admin-reset-password` deploy อยู่ (ถ้าโปรแกรมแจ้งให้อัปเดต ทำตามข้อความในโปรแกรม)

## การอัปเดตโปรแกรม

1. อัปโหลด `index.html` ไฟล์ใหม่ทับไฟล์เดิมใน repo นี้ (Add file → Upload files → Commit)
2. รอ 1–2 นาที ให้ GitHub Pages อัปเดต
3. ทุกเครื่องรีเฟรชหน้าเว็บ (คอม: Ctrl+Shift+R · มือถือ: ปิดแท็บแล้วเปิดใหม่)
   ตรวจว่ามุมจอแสดงเลขเวอร์ชันใหม่ · เครื่องที่ยังเป็นเวอร์ชันเก่าจะถูกกันไม่ให้บันทึกทับข้อมูล และโปรแกรมจะแจ้งให้รีเฟรช

## การใช้งานครั้งแรก / บัญชีผู้ใช้

1. แอดมินเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านของแอดมิน
2. ⚙️ การตั้งค่า → 🔑 บัญชีผู้ใช้งาน → สร้างบัญชีให้พยาบาลแต่ละคน (เลือกบทบาท และผูกกับรายชื่อพยาบาล)
3. พยาบาลเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านที่ได้รับ — ใช้ได้ทุกเครื่อง
